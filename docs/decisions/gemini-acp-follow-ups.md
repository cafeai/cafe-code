# Gemini ACP follow-ups and background work

Decided 2026-11-20 12:10:32 JST (UTC+0900).

Google documents sending another prompt to steer a running Antigravity ACP session. In an isolated CLI 1.5.13 session, sending the second prompt during the first reply caused the original request to settle immediately. Output then continued until the second request settled. Neither response echoed a client message ID or carried the native turn identity. [Antigravity ACP guide](https://antigravity.google/docs/ide/extensions/acp/) · [ACP prompt response](https://agentclientprotocol.com/protocol/v1/prompt-turn)

Cafe authorizes a steer against the exact current local turn and its held native session. A bounded FIFO transport offer ties submission to that owner before Stop can reserve retirement. The adapter admits one concurrent follow-up and joins all of its accepted JSON-RPC requests before settling the visible turn. Native ACP may shift the follow-up to a later reply when the foreground completes at the same time. Cafe associates the returned output with the same user-authorized conversation. Only an explicit pre-admission refusal can return the message to the queue. An unknown receipt retires the owner and retains a warning and the input, without replay. Transport queue admission and grouped completion grant no message consumption or permission authority.

CLI 1.5.10 and newer can send detached replies, tools, and approvals after the original prompt response. Cafe accepts authenticated session updates from that exact owner and records detached reply snapshots independently of the foreground transcript. Exact tool identities and terminal edges support read-only task liveness across foreground turns. The provider's callback and configuration checks still govern approvals and Stop. ACP supplies no general background roster and no reliable turn identifier for untagged output after the next foreground request starts. Cafe retains counts only for observations it can bind to a live tool and its runtime. [Antigravity changelog](https://antigravity.google/docs/changelog#v1510)
